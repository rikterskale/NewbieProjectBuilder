# Roadmap

## Phase 1 — Safe diagnostics and logging

Status: implemented in the MVP.

- OS and tool detection.
- Exact package plans.
- Stable error catalog.
- Redacted verbose logging.
- Dry-run and support bundles.

## Phase 2 — Conservative project generator

Status: implemented in the MVP.

- Beginner questionnaire.
- Name and destination validation.
- Backups and no-silent-overwrite behavior.
- Starter policies and novice guides.
- Python CLI runnable template.

## Phase 3 — GitHub integration

Status: implemented at a guarded foundation level.

- Browser authentication.
- Account verification.
- Confirmed repository creation.
- Confirmed first publication.
- Feature-branch-only later publishing.

Planned additions:

- Draft pull-request creation from generated projects.
- Readable CI-status summaries and failed-log download.
- Previewable repository ruleset installation.
- Security-feature configuration guidance and verification.

## Phase 4 — AI workflow integration

Status: foundation implemented.

- Superpowers verification guidance.
- Small Agency Agents specialist roster.
- Generated kickoff prompt and workflow documentation.

Planned additions:

- Codex plugin-state verification through supported official interfaces.
- Template-specific specialist selection.
- Generated specification and plan checklists.
- Project-local AI tooling inventory and update report.

## Phase 5 — Distribution and acceptance testing

Planned:

- Signed Windows executable and installer.
- Graphical wizard backed by the same tested Python services.
- Linux packages for supported distributions.
- Release checksums and signatures.
- Automatic update checks with user-controlled installation.
- Clean Windows 10/11, Ubuntu, Debian, and Kali virtual-machine acceptance tests.
- Screen-reader and keyboard-only usability testing.
- Localized beginner messages after the English workflow stabilizes.

## Phase 6 — More templates

Planned only after each stack has a stable, novice-maintainable architecture:

- FastAPI service.
- Static website.
- Small web application.
- Desktop application.
- Local AI application.
- Authorized security-tool template with mandatory scope enforcement.

Each template must ship with platform setup, tests, CI, security checks, expected output,
troubleshooting, uninstall or cleanup, and a verified upgrade path.
