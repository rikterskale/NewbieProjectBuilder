# AI Integrations

## Operating model

Superpowers is the sole software-development workflow controller. Agency Agents provides a
small set of specialist perspectives. Neither tool is trusted as proof that work is correct;
fresh tests and verification commands remain authoritative.

## Superpowers

The builder reports whether Codex appears available and gives the beginner exact guidance to
open the Codex Plugins interface and verify Superpowers. Plugin installation remains guided
because availability may depend on the Codex build, account, workspace policy, and
administrator settings.

Expected workflow:

1. Brainstorm and approve the design.
2. Save and approve a written specification.
3. Write and approve the implementation plan.
4. Use an isolated feature branch or worktree.
5. Implement through test-driven development.
6. Review tasks and the whole branch.
7. Run fresh verification before claiming completion.
8. Ask the project owner before push, pull request, merge, release, deploy, delete, or other
   external side effects.

## Agency Agents core roster

The optional installer selects only:

- Product Manager.
- Software Architect.
- Code Reviewer.
- Test Automation Engineer.
- AppSec Engineer.
- DevOps Automator.
- Technical Writer.
- Reality Checker.

The builder does not intentionally activate NEXUS or Agents Orchestrator. Additional
specialists should be installed only when a project has a real need.

## Trust and safety rules

- Never place credentials in an AI prompt.
- Review every proposed command before running it.
- Do not let an AI disable security, tests, or branch protections to obtain a green result.
- Do not accept “done” without fresh command output and exit codes.
- Do not permit automatic merge, release, deployment, or deletion.
- For authorized security projects, keep written authorization, allowlists, denylists,
  prohibited actions, evidence rules, and cleanup requirements in the repository.

## Troubleshooting

When Superpowers is unavailable, the builder still creates local projects and documentation.
Use the Codex Plugins screen and ask a workspace administrator if policy blocks installation.
When Agency Agents scripts are unavailable on Windows, use the official desktop application
and install only the core roster.
